# Mini Jeu P5.js

Un mini-jeu développé avec P5.js - Hors ligne

## Structure du projet

```
├── index.html       # Fichier principal (ouvre le jeu dans le navigateur)
├── sketch.js        # Code du jeu P5.js
├── style.css        # Styles CSS
├── assets/          # Dossier pour les ressources (images, sons, etc.)
│   └── faces/       # Dossier pour les portraits
└── README.md        # Ce fichier
```

## Pour démarrer

1. Ouvrez `index.html` dans votre navigateur
2. Le jeu doit apparaître avec un carré bleu contrôlable
3. Utilisez les flèches du clavier pour bouger

## Développement

- Modifiez `sketch.js` pour ajouter la logique du jeu
- Modifiez `style.css` pour changer l'apparence
- Ajoutez des images/ressources dans le dossier `assets/`

## Notes

- Ce projet utilise P5.js via CDN (en ligne)
- Pour une utilisation hors ligne complète, téléchargez la bibliothèque P5.js localement
